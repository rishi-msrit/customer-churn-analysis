Model Limitations

  • This is a static training dataset. The model does not learn from new customer behaviour after deployment.
  • Logistic regression assumes a linear decision boundary. Non-linear patterns (e.g. interaction between tenure and fibre internet) are not captured.
  • ROC-AUC and accuracy are reported on a single hold-out split; reported scores may overestimate real-world performance slightly.
  • Several features (gender, partner, dependents) had no statistically significant association with churn in this dataset but are included in the model for completeness.
About this page
  • Confusion MatrixA 2x2 count of correct and incorrect predictions on the held-out test set. The top-right cell (false positives) and bottom-left cell (false negatives) represent the two types of error.
  • ROC CurvePlots true positive rate against false positive rate across all classification thresholds. AUC of 0.84 means the model ranks a random churner above a random non-churner 84% of the time.
  • Precision-Recall CurveMore informative than ROC when classes are imbalanced. A drop in precision at high recall means the model catches more churners but also flags more non-churners.
  • Feature ImportanceAbsolute logistic regression coefficient magnitude after standardisation. Red bars increase churn probability; green bars reduce it.
